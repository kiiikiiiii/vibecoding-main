3. 시퀀스: 노트 저장

sequenceDiagram
  actor U as 사용자
  participant E as NoteEditor
  participant C as NotesContext
  participant A as api/notes.ts
  participant S as json-server
  participant P as App

  U->>E: 저장 클릭
  E->>E: handleSave · 제목이 비면 alert 후 종료
  E->>E: setSaving(true)
  alt isCreating (새 노트)
    E->>C: addNote(title, content)
    C->>A: createNote · title, content
    A->>S: POST /notes · createdAt·updatedAt 추가
    S-->>A: 생성된 Note (id 자동 생성)
    A-->>C: Note
    C->>C: setNotes · 목록 끝에 추가
  else 기존 노트 편집
    E->>C: editNote(id, title·content)
    C->>A: updateNote(id, updates)
    A->>S: PATCH /notes/(id) · updatedAt 갱신
    S-->>A: 수정된 Note
    A-->>C: Note
    C->>C: setNotes · 같은 id 항목 교체
  end
  C-->>E: notes 변경 → 구독 컴포넌트 리렌더
  E->>P: onDone()
  P->>P: setIsCreating(false)
  E->>E: setSaving(false) · finally
  Note over E,S: 실패하면 catch에서 console.error 후 alert
